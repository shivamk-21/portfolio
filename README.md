## Project Overview
Welcome to the **portfolio** project! This repository hosts a **React Frontend Application** showcasing personal projects, skills, and experiences. It's designed to highlight the creator's work in development and data science, providing an interactive platform for users to explore various sections dedicated to projects, education, and more.

## 🌟 Features
- **Responsive Design:** Seamlessly adapts to different screen sizes.
- **Smooth Scrolling Navigation:** Allows easy access to different sections with scrolling effects.
- **Interactive Projects Showcase:** Display detailed descriptions and links to various projects.
- **Dynamic Content Management:** Easily manage and add new projects or experiences via JavaScript objects.

## 📦 Installation
### Prerequisites
Before installing the project, ensure you have:
- Node.js (version 12 or higher)
- npm (Node Package Manager)

### Step-by-Step Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/shivamk-21/portfolio.git
   ```
2. Navigate into the project directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the root directory with the following content:
   ```
   PORT=3000
   NODE_ENV=development
   ```

5. Start the development server:
   ```bash
   npm start
   ```

## 💻 Usage
To view your portfolio application after starting the server, navigate to `http://localhost:3000` in your web browser.

### Key Files & Directories Explained:
- `public/index.html`: The main HTML file that serves as a template for the React application.
- `src/App.js`: The root component where all other components are integrated.
- `src/components/`: Contains reusable UI components such as Navigation (`Nav`) and Footer.
- `src/pages/`: Individual page components that encapsulate specific sections of your portfolio like Education and Experience details.
- `src/styles/`: CSS files for styling each of the components/pages.
